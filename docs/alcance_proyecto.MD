# Alcance de FutBot

**I.S.S (Ingeniería del Software Survival)**
Fecha: 21/08/2026
Versión del documento: 0.1

FutBot es un videojuego en linea en el cual se pueden jugar partidos de football en vivo entre clubes. Cada usuario crea su propio club, jugadores y sus comportamientos. Ademas de esto el club puede unirse o crear ligas, ya sea publicas o privadas para jugar con amigos.

# Alcance del Poducto
### Modulo de Usuarios
Este modulo consistira en registrar, iniciar sesion y modificar el avatar de un determinado usuario.
- Registrarse: El usuario puede crear su cuenta con los datos correspondientes para asi poder acceder al sistma
- Setear avatar: El usuario puede asignar/cambiar el avatar de su club

### Modulo Jugadores
Este modulo consistira en el manejo de los jugadores en general.
- Creacion: El usuario puede crear jugadores que tiene nombre y su PACSS
- Elminacion:
- Asignacion de comportamiento: El usuario puede asignar distintos comportamientos a su jugador tantas veces como desee.

### Modulo Comportamientos
- Creacion: El usuario puede crear tantos comportamientos como desee para sus jugadores. Estos pueden crearse incluso durante un partido. Se realizara a travez de una programacion en bloques.
- Eliminacion: El usuario podrá eliminar un comportamiento siempre y cuando este no este en uso por un jugador.
- Edicion: El usuario puede modificar un comportamiento siempre y cuando este no este en uso por un jugador.

## Modulo Ligas
- Creacion: El usuario definira el nombre, privacidad (publica o provada), numero minimo y maximo de clubes (no menos de 3), duracion de los partidos.
- Inicio: El club creador de la liga podra darle inicio cuando desee, siempre y cuando el cupo minimo de juagdores este completo.
- Cancelacion: El club creador puede cancelar la liga si esta aun no ha sido iniciada.
- Abandono: Los demas clubes pueden abandonar la liga siempre y cuando esta no haya empezado
- Cada liga tiene su fixture y su tabla de puntaje.
